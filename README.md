# منظومة النتائج — نسخة تجريبية على Render

هذه الحزمة مخصصة للعرض فقط، وبها بيانات اصطناعية. لا ترفعي أو تدخلي بيانات طلاب حقيقية.

## Render

أنشئي Web Service من هذا المستودع باختيار Blueprint (`render.yaml`). الخطة `free`، والخادم يستمع على `0.0.0.0:$PORT` عند التشغيل على Render. قاعدة SQLite مؤقتة على الخطة المجانية؛ قد تعود البيانات إلى حالة العرض بعد توقف الخدمة بسبب الخمول أو إعادة النشر.

عند فتح الرابط لأول مرة، أنشئي حساب مشرف النظام بكلمة مرور لا تقل عن 12 حرفًا، ثم سجّلي الدخول. لا توجد كلمة مرور افتراضية في المستودع.

## محليًا

`python server.py` ثم افتحي `http://127.0.0.1:8765/`.
